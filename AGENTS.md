# terraform-azurerm-virtual-network

Terraform module for Azure Virtual Network. Wraps `azurerm_virtual_network` and `azurerm_subnet`.

## Terraform resources

| Resource | Local name | Role |
| -------- | ---------- | ---- |
| `azurerm_virtual_network` | `main` | Primary resource |
| `azurerm_subnet` | `subnets` | Repeatable — `for_each` by `name` |

## Module-specific conventions

- `locals.tf` contains `service_delegation_actions` — a map from delegation service name to its required Azure RBAC actions. Used exclusively in the `dynamic "delegation"` block: `actions = formatlist("Microsoft.Network/%s", local.service_delegation_actions[each.value.delegation])`.
- Adding a delegation service requires updating **both** `locals.tf` (new key + actions) **and** the `delegation` validation allowlist in `var.subnets`. They must stay in sync. Use the Terraform Registry MCP to verify the required actions before adding.
- `resource_group_name` and `virtual_network_name` in `azurerm_subnet` are sourced from `azurerm_virtual_network.main`, never from `var.*`.
- `var.subnets` has four validation blocks that must all remain consistent when adding new allowed values: `address_prefixes` (CIDR), `service_endpoints` (allowlist of 10), `private_endpoint_network_policies` (4 values), `delegation` (~55 service names).

## `variables.tf`

```hcl
# Required scalar
variable "name" {
  type        = string
  description = "The name of the virtual network."
}

# Optional scalar — default = null
variable "ddos_protection_plan_id" {
  type        = string
  default     = null
  description = "The ID of DDoS Protection Plan."
}

# Optional list — default = []
variable "dns_servers" {
  type        = list(string)
  default     = []
  description = "List of IP addresses of DNS servers."
  validation {
    condition     = can([for ip in var.dns_servers : cidrnetmask("${ip}/32")])
    error_message = "All value must be a valid IP address."
  }
}

# Repeatable sub-resources
variable "subnets" {
  type = list(object({
    name                                          = string
    address_prefixes                              = list(string)
    default_outbound_access_enabled               = optional(bool, false)
    service_endpoints                             = optional(list(string))
    delegation                                    = optional(string)
    private_endpoint_network_policies             = optional(string, "Disabled")
    private_link_service_network_policies_enabled = optional(bool)
  }))
  default     = []
  description = "List of objects that represent the configuration of each subnet."
  # ... four validation blocks
}

# Enum validation
variable "encryption_mode" {
  type        = string
  default     = null
  description = "..."
  validation {
    condition     = var.encryption_mode == null ? true : contains(["AllowUnencrypted", "DropUnencrypted"], var.encryption_mode)
    error_message = "The encryption mode must be either 'AllowUnencrypted' or 'DropUnencrypted'."
  }
}
```

## `main.tf`

- Resource blocks only — no `provider`, no `data`, no `locals`.
- Never `count` for named resources — use `for_each`.
- Never declare a `provider` block.
- Reference child attributes via the primary resource: `azurerm_virtual_network.main.name`, never `var.name`.

```hcl
# Optional single block
dynamic "ddos_protection_plan" {
  for_each = var.ddos_protection_plan_id != null ? [""] : []
  content {
    id     = var.ddos_protection_plan_id
    enable = true
  }
}

# Repeatable sub-resource
resource "azurerm_subnet" "subnets" {
  for_each             = { for subnet in var.subnets : subnet.name => subnet }
  resource_group_name  = azurerm_virtual_network.main.resource_group_name
  virtual_network_name = azurerm_virtual_network.main.name
  # ...
}
```

## `outputs.tf`

- Every output requires `value` and `description`.
- Source from the resource, never from `var.*`.

```hcl
# Scalar
output "name" {
  value       = azurerm_virtual_network.main.name
  description = "The name of the virtual network."
}

# Collection — map keyed by name
output "subnets" {
  value       = { for subnet in azurerm_subnet.subnets : subnet.name => subnet }
  description = "Blocks containing configuration of each subnet."
  # module.MODULE_NAME.subnets["SUBNET_NAME"].id
}

# Block from computed attribute
output "ddos_protection_plan" {
  value       = azurerm_virtual_network.main.ddos_protection_plan
  description = "Block containing configuration of ddos protection plan."
}
```

## `CHANGELOG.md`

Categories in order (omit empty): `FEATURES`, `ENHANCEMENTS`, `BREAKING CHANGES`, `DEPRECATIONS`, `BUG FIXES`. Sub-parameters as `parent.child` (e.g. `subnets.delegation`).

```markdown
## UNRELEASED

* dependencies: updating to `v4.27.0` minimum of `hashicorp/azurerm` provider.
```

## Tests

### `tests/environment`

- `workspace_id = uuid()` (VNet names allow hyphens, no special format needed).
- Location: `"Spain Central"`.
- Outputs: `workspace_id`, `resource_group_id`, `resource_group_name`, `resource_group_location`, `resource_group_tags`.

### `tests/testing.tftest.hcl`

```hcl
provider "azurerm" { features {} }

run "setup" {
  module { source = "./tests/environment" }
}

variables {
  location      = run.setup.resource_group_location
  tags          = run.setup.resource_group_tags
  address_space = ["10.1.0.0/16"]
  subnets       = [{ name = "subnet1", address_prefixes = ["10.1.0.0/24"] }]
}

run "plan" {
  command = plan
  variables {
    name                = run.setup.workspace_id
    resource_group_name = run.setup.resource_group_name
  }
}

run "apply" {
  command = apply
  variables {
    name                = run.setup.workspace_id
    resource_group_name = run.setup.resource_group_name
  }
}
```

### Assert patterns

```hcl
# Scalar
assert {
  condition     = azurerm_virtual_network.main.bgp_community == var.bgp_community
  error_message = "The virtual network bgp_community input variable is being modified."
}

# list — requires tolist()
assert {
  condition     = tolist(azurerm_virtual_network.main.address_space) == var.address_space
  error_message = "The virtual network address_space input variable is being modified."
}

# for_each sub-resource by name
assert {
  condition     = azurerm_subnet.subnets["subnet1"].address_prefixes == ({ for s in var.subnets : s.name => s })["subnet1"].address_prefixes
  error_message = "The subnet address_prefixes input variable is being modified."
}

# Optional dynamic block — index [0]
assert {
  condition     = azurerm_virtual_network.main.encryption[0].enforcement == var.encryption_mode
  error_message = "The virtual network encryption_mode input variable is being modified."
}

# Apply — resource ID
assert {
  condition     = azurerm_virtual_network.main.id == "${run.setup.resource_group_id}/providers/Microsoft.Network/virtualNetworks/${run.setup.workspace_id}"
  error_message = "The Virtual Network ID is not as expected."
}

# Apply — child resource ID
assert {
  condition     = azurerm_subnet.subnets["subnet1"].id == "${run.setup.resource_group_id}/providers/Microsoft.Network/virtualNetworks/${run.setup.workspace_id}/subnets/subnet1"
  error_message = "The subnet1 ID is not as expected."
}

# Apply — output verification
assert {
  condition     = output.id == azurerm_virtual_network.main.id
  error_message = "The Virtual Network ID output is not as expected."
}

# Apply — collection output length
assert {
  condition     = length(output.subnets) == length(azurerm_subnet.subnets)
  error_message = "The Virtual Network subnets output is not as expected."
}
```

## Examples

- Single `main.tf` per example — no other files.
- Starts with `azurerm_resource_group` at `"Spain Central"`.
- `source = "aztfm/virtual-network/azurerm"`, `version = ">= 5.0.0"`.
- `resource_group_name` and `location` always reference `azurerm_resource_group.rg.*`.
- Directory name: `virtual-network-with-<feature>/`.
